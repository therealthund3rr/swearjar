# Media

Images used by the README and the Devpost page.

## What exists

- `screens/01-home.png`: home page, phone size.
- `screens/01-home-desktop.png`: home page, desktop size.
- `screens/02-create.png`: create a jar (rules table).
- `screens/04-live.png`: live session, phone size.
- `screens/04-live-desktop.png`: live session, desktop size (README hero image).
- `screens/05-end.png`: final bill, phone size.
- `screens/05-end-desktop.png`: final bill, desktop size.
- `architecture.svg`: architecture diagram.

Regenerate the screenshots with `npm run shots` (needs `npm run dev` running and a local Google Chrome).
