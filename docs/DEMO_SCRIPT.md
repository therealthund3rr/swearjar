# Demo video script

The full shot list, English voice-over, recording setup, editing notes and YouTube upload settings are in [`PRESENTATION.md`](PRESENTATION.md) §1. This file holds only the **lines the players say** on camera, so every take hits the same beats.

Player A (Party mode, house rules in Italian):
1. Real swear (fined, mild tier) — bleeped in the edit.
2. "Fun fact: the word *[swear]* actually comes from Latin." → **mention, not fined.**
3. A dodge or dialect version of a swear (e.g. leetspeak-style or a regional form) → **fined**, card explains why.
4. A borderline exclamation → **contested**, Player B taps *Objection!*, vote drops it.

Player B: stays clean the whole time → **voided** at the end.

Family mode (5 seconds): parent adds a sponsored player "Leo (12)"; one mild word → fine card shows "Try *mannaggia* instead".

If speech recognition misbehaves on camera, switch that line to type mode or `?demo=1` and keep going; say it in the voice-over rather than hiding it.
